# Download Chorus

Official downloads for **Chorus**, a premium Minecraft client.

Builds here are produced automatically by GitHub Actions from a clean checkout of the
source — not from anyone's machine — so a given version is always the same bytes.

## Get it

Head to [**Releases**](../../releases) and take one of:

| File | Use it if |
| --- | --- |
| `Chorus-Setup-<version>.exe` | You want Chorus installed properly — Start Menu entry, desktop shortcut, and an uninstaller. Most people want this. |
| `Chorus-<version>.exe` | You want to just run it. Nothing is installed and nothing is written outside your normal data folder. |

Windows x64. You do not need to install Java or Minecraft first — Chorus handles that.

Your worlds, accounts and settings live in `%APPDATA%\Chorus` and are never removed by
uninstalling.

## "Windows protected your PC"

Expected on first launch. The builds are not code-signed yet, so SmartScreen warns about any
publisher it has not seen before. Click **More info** → **Run anyway**.

## Source

The source lives in a private repository. This repo carries releases only — there is no code
here to browse, and issues opened against it will not reach the developers.
